# 정보분석 경진대회 현장 심사 시스템

과장님들이 **로그인 없이** 휴대폰으로 QR을 찍어 점수를 입력하고, 발표 순서 추첨부터 최우수 발표까지 스크린 하나로 진행하는 Streamlit 앱입니다.

## 화면 구성 (주소 하나, 화면 세 개)

| 화면 | 주소 | 누가 / 어디서 |
|---|---|---|
| 심사위원 | `https://앱주소/` | 과장님 휴대폰 (스크린의 QR) |
| 스크린 | `https://앱주소/?view=screen` | 대강당 프로젝터 |
| 관리 | `https://앱주소/?view=admin` | 기획팀 (노트북 또는 휴대폰, PIN 필요) |

- **관리 화면은 스크린과 다른 기기에서** 여는 걸 권장합니다. 예를 들어 노트북은 스크린만 띄우고, 진행 담당자는 휴대폰으로 관리 화면을 조작합니다.
- 스크린은 2초마다, 심사위원 화면은 3초마다 자동으로 갱신됩니다.

## 규칙 (현재 설정)

- **평가 방식 (2026 본청 기준)**: 평가기준(실현 가능성 40 · 발굴 참신성 30 · 주제 타당성 30)을 참고해 팀마다 **종합점수 1~5점** 하나를 고릅니다. 5점 매우우수, 4점 우수, 3점 보통, 2점 미흡, 1점 매우미흡입니다. 휴대폰 화면의 '평가기준 보기'에서 기준표를 볼 수 있습니다.
- **본인 관실 제외**: 심사위원의 소속 관실이 발표팀의 소속 관실과 같으면 그 팀은 평가 화면 대신 "평가 제외" 안내가 나옵니다.
- **집계**: 팀마다 받은 총점에서 **최고점·최저점을 1개씩 빼고 평균**을 냅니다. 본인 관실 제외로 팀별 심사 인원이 8명 또는 9명으로 달라지므로, 합계가 아니라 평균으로 비교합니다.
- **동점**: 반영 평균이 같으면 전체 평균으로 비교합니다. 그래도 같으면 관리 화면에서 심사위원장 결정에 따라 최우수 팀을 고릅니다.
- **발표**: 스크린과 심사위원 화면에는 **최우수 1팀만** 나옵니다. 우수 4팀은 설정에서 함께 띄울 수도 있습니다.

## 익명 처리

- 스크린, 심사위원 화면, 결과 엑셀 어디에도 **누가 몇 점을 줬는지는 나오지 않습니다**. 엑셀에는 팀별로 받은 점수를 높은 순으로만 정리합니다.
- 과장님들끼리는 서로의 점수를 볼 수 없습니다.
- 다만 집계를 하려면 원본 데이터가 서버의 파일에 남습니다(관실이 아닌 무작위 ID로 저장). "화면과 기록에서 익명"이라고 안내해 주세요.

## 1. 배포하기 (Streamlit Community Cloud, 무료)

1. **GitHub 저장소 만들기**: 이 폴더의 파일을 전부 올립니다(`data/` 폴더는 올리지 않음). 실제 팀명·관실명은 저장소가 아니라 관리 화면에서 입력해도 됩니다.
2. [share.streamlit.io](https://share.streamlit.io)에 GitHub 계정으로 로그인 → **Create app** → 저장소 선택, Main file은 `app.py`.
3. **Advanced settings**
   - Python 버전: **3.12**
   - Secrets에 아래 두 줄 입력 (`.streamlit/secrets.toml.example` 참고)
     ```
     admin_pin = "관리자 PIN"
     judge_code = "4자리 숫자"
     ```
4. **Deploy** → 주소(예: `https://xxxx.streamlit.app`)가 나옵니다.
5. **공개 설정 확인**: 과장님들이 로그인 없이 들어오려면 앱이 **공개(public)** 상태여야 합니다. 앱 화면 오른쪽 위 **Share**에서 공개로 되어 있는지 확인하세요. 비공개 GitHub 저장소로 만든 앱은 기본이 비공개입니다.
6. 관리 화면(`/?view=admin`) → **설정** 탭 → "접속 주소"에 4번의 주소를 넣고 저장합니다. QR에 이 주소가 들어갑니다.

> **보안 참고**: 앱이 공개 상태라 주소를 아는 사람은 누구나 첫 화면에 들어올 수 있습니다. 그래서 심사위원 자리를 고를 때 **확인 코드(judge_code)**를 입력하도록 했습니다. 코드는 스크린에 띄우지 말고 **심사 자료(종이)에만** 적어 두세요. 기관의 외부 웹서비스 사용 지침이 있다면 확인해 주세요. 앱에 저장되는 것은 팀명, 관실명, 점수뿐입니다.

> **잠자기 주의**: Community Cloud 앱은 한동안 아무도 접속하지 않으면 잠자기 상태가 됩니다. 행사 **30분 전에 스크린 화면을 먼저 열어** 깨워 두세요. 스크린이 켜져 있는 동안은 계속 깨어 있습니다.

### (대안) 행사장 노트북에서 직접 실행

인터넷 외부 서버를 쓰기 어렵다면, 노트북과 휴대폰이 **같은 와이파이**에 있을 때 이렇게 쓸 수 있습니다. 기관 와이파이는 기기끼리 접속을 막는 경우가 많으니 리허설에서 꼭 확인하세요.

```
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0
```

설정 탭의 접속 주소에 `http://노트북IP:8501`을 넣습니다.

## 2. 리허설 (11/2 월 권장)

- [ ] 설정 탭에 실제 **팀명·소속 관실·정보분석명**과 심사위원 9명의 **소속 관실**을 입력합니다. 관실 이름은 팀과 심사위원 양쪽에 **똑같이** 써야 본인 관실 제외가 작동합니다.
- [ ] 스크린 화면을 실제 프로젝터에 띄워 글자 크기와 QR이 잘 보이는지 확인합니다.
- [ ] 과장님 2~3분(또는 기획팀 휴대폰 여러 대)으로 QR 접속 → 관실 선택 → 코드 입력 → 점수 제출을 해 봅니다.
- [ ] 관리 화면에서 추첨 → 발표 시작 → 평가 요청 → 마감 → 최우수 발표까지 한 바퀴 돌려 봅니다.
- [ ] 끝나면 **데이터 탭 → 점수·진행 초기화**를 누릅니다. 설정과 접속 정보는 남습니다.
- [ ] 데이터 탭에서 **백업 파일**을 하나 내려받아 둡니다. 서버가 재시작되면 설정이 settings.json 상태로 돌아가는데, 이 백업으로 되살릴 수 있습니다.
- [ ] 종이 심의표 몇 장을 예비로 준비합니다(대리 입력용).

## 3. 당일 진행 순서 (관리 화면 → 진행 탭)

1. 스크린에 대기 화면과 QR이 나옵니다. 과장님들이 접속하면 오른쪽 아래 점이 하나씩 켜집니다.
2. **🎲 발표 순서 추첨**을 누르면 스크린에서 순서가 한 팀씩 정해지는 장면이 나옵니다.
3. **▶ 첫 발표 시작**을 누르면 스크린에 "발표 1/5 · 팀명 · 발표 중"이 나옵니다. 이때부터 과장님 휴대폰에 평가 화면이 뜹니다.
4. 발표가 끝나면 **발표 종료 · 평가 요청**을 누릅니다. 스크린에 "평가 입력 중 6/8"처럼 제출 인원이 나옵니다.
5. 모두 제출하면 **평가 마감 · 다음 발표로**를 누릅니다. 미제출자가 있으면 관실명을 보여 주고 한 번 더 확인합니다.
6. 마지막 팀을 마감하면 스크린에 "집계 중"이 나옵니다.
7. **🏆 최우수 발표**를 누르면 스크린에 "최우수상 · 발표합니다" 연출 뒤에 팀명이 나옵니다.
8. **결과 탭 → 결과 엑셀 내려받기**로 결재용 자료를 받습니다.

## 4. 이럴 땐

| 상황 | 해결 |
|---|---|
| 과장님이 엉뚱한 관실을 눌렀어요 | 휴대폰 화면 맨 아래 "다른 분이 이 휴대폰을 쓰시나요?"에서 다시 선택, 또는 데이터 탭에서 해당 자리 **해제** |
| 휴대폰이 꺼졌거나 브라우저를 닫았어요 | 스크린의 QR을 다시 찍고 같은 관실을 선택 (입력한 점수는 남아 있음) |
| 휴대폰 입력이 어려운 분이 계세요 | 종이 심의표를 받아 **대리 입력** 탭에서 입력 (마감된 팀도 가능) |
| 실수로 다음 팀으로 넘겼어요 | 진행 탭 **◀ 한 단계 되돌리기** (마감한 팀이 다시 열림) |
| 1위가 동점이에요 | 진행 탭에 동점 팀이 나오면 심사위원장 결정대로 선택 후 발표 |
| 앱이 재시작되어 설정이 초기값이 됐어요 | 데이터 탭에서 미리 받아 둔 **백업 파일로 되살리기** |
| 발표 장면을 다시 보여 주고 싶어요 | 진행 탭 **발표 장면 다시 재생** |

## 파일 구성

- `app.py`: 화면(심사위원·스크린·관리)
- `core.py`: 저장, 진행 단계, 집계, 엑셀 내보내기
- `screens.py`: 프로젝터 화면 디자인
- `settings.json`: 기본 설정(팀·심사위원·평가 항목). 서버가 재시작되면 이 값으로 시작합니다.
- `.streamlit/config.toml`: 화면 테마
